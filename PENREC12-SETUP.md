# PENREC12 setup
1. Run `INSTALL-PENREC12.command` and select the current working PENREC11 project folder (the folder containing `package.json`).
2. In Supabase, open SQL Editor and run `supabase/migrations/20260731_penrec12_customer_dashboard.sql` once.
3. Start the project with `npm run dev`.
4. Sign in and open `/account`.
