# PENREC11 — Authentication & Account Foundation

## Added

- Supabase email/password registration and sign-in
- Email verification callback
- Forgot-password and secure password reset flow
- Persistent authenticated sessions
- Customer account dashboard shell
- PENREC Studio admin dashboard shell
- Role-based access for customer, staff, admin and super admin
- Protected `/account`, `/admin` and `/admin/users` routes
- Account-aware header navigation
- Supabase database migration with Row Level Security
- Environment-variable template and setup guide

## Deliberately reserved for later releases

- Shopping basket and checkout
- Paid digital downloads
- Order history and fulfilment tracking
- Wishlists stored in the database
- Two-factor authentication
- Admin role-editing interface

These items now have the account and permission foundation they require.
